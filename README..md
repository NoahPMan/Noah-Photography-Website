# Noah Manaigre Photography

A professional photography portfolio showcasing sports, portraits, street photography, and wildlife captured in Winnipeg, Manitoba.

## Live Website

[View Noah Manaigre Photography](https://noahpman.github.io/Noah-Photography-Website/)

## About the Website

This is the personal photography portfolio of Noah Manaigre, a Winnipeg-based photographer focused on capturing authentic moments, strong compositions, and images that feel natural rather than staged.

The website features dedicated galleries for:

- Sports photography
- Portrait photography
- Street photography
- Wildlife photography

Visitors can also learn more about the photographer, explore available photography packages, and submit a booking inquiry through the website.

## Services

Available photography services include:

- Portrait sessions
- Graduation sessions
- Engagement and couples sessions
- Family sessions
- Individual athlete coverage
- Team and tournament coverage
- Event photography
- Custom and wedding inquiries

## Features

- Responsive design for desktop, tablet, and mobile devices
- Organized photography galleries
- Full-screen image lightbox
- Mobile navigation menu
- Photography packages and pricing
- Online booking inquiry form powered by Formspree
- Accessible keyboard navigation
- Instagram integration
- Custom favicon
- Reduced-motion support
